# Image sources and provenance notes

This project keeps its visual assets locally in the `static/images/` directory and uses them only where the repository already contains a matching local file or a clearly labeled placeholder. Several original archive records were incomplete, so some images are intentionally marked as "unknown" instead of being described as verified historical photographs.

## General note on provenance

The source package used for this project does not preserve complete metadata for every historical image. When the original archive or a known public source was missing, the site preserves the honest status: "дерек қажет" (needs data), "сәйкестендіру қажет" (verification needed), or a clearly labeled local placeholder. No image is deliberately presented as a verified historical photograph unless the project data itself already identified it as such.

## Important project rule

If a picture’s source, date, and identity cannot be verified, the project does not present it as a historical photo of a named place or person. It is either labeled as a placeholder, an unverified record, or a general current view. This protects the project from fabricating local history and keeps the website honest.

## External references used by the project

The site also references some public or structured sources in the JSON data under `data/sources.json`. Those entries are documented in the project’s source records and may include external URLs. The project does not hotlink core media files from third-party sites; it stores local copies where available and uses remote sources only as citations when built into the source metadata.
