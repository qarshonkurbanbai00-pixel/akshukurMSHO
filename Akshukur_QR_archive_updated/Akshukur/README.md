# Ақшұқыр — цифрлық шежіре

Бұл проект — Ақшұқыр ауылының тарихын, мәдениетін, мектеп тарихын, тарихи орындарын және дереккөздерін көрсетуге арналған Flask сайт. Сайт жергілікті JSON, HTML шаблондар, CSS және JS арқылы жұмыс істейді; сыртқы API немесе күрделі бекенд қажет емес.

## Жоба құрылымы

- `app.py` — Flask маршруты, API және HTML render логикасы
- `data/` — тарих, орындар, карталар, фото, дереккөздер және ауызша тарих деректері
- `templates/` — Flask HTML шабондары
- `static/` — CSS, JS, суреттер, 3D кітапханалары және медиа
- `tests/` — қолжетімді функционалдық тексерулер
- `IMAGE_SOURCES.md` — суреттердің бастапқы дереккөзі мен мәртебесі

## Windows-та іске қосу

1. ZIP архивін шығарып, проекктің негізгі папкасына кіріңіз.
2. Python 3.10+ орнатылғанын тексеріңіз. Егер жоқ болса, https://www.python.org/downloads/ мекенжайынан орнатыңыз. Орнату кезінде “Add Python to PATH” белгісін қойыңыз.
3. Терминал (PowerShell немесе cmd) ашып, папкада мыналарды орындаңыз:

```bat
python -m pip install -r requirements.txt
python app.py
```

4. Браузерде http://127.0.0.1:5000/ ашыңыз.
5. Қол жетімді негізгі беттер:
   - http://127.0.0.1:5000/
   - http://127.0.0.1:5000/tarikh
   - http://127.0.0.1:5000/rekonstrukciya
   - http://127.0.0.1:5000/mektep
   - http://127.0.0.1:5000/karta
   - http://127.0.0.1:5000/auyzsha-tarikh
   - http://127.0.0.1:5000/izdeu

## run.bat

`run.bat` файлында проект директориясы, Python 3.10+ тексеруі, Flask dependency check және серверді іске қосу логикасы бар. Файлды екі рет басып, сайтты ашуға болады.

## Тексеру

Осы QR/фотоархив нұсқасының негізгі тексеруі (тек Flask керек):

```bat
python -m unittest discover -s tests -p test_qr_archive_update.py -v
```

Компьютер/телефон браузерінде тексеру (әзірлеушіге арналған, сайтты іске қосуға міндетті емес):

```bat
python -m pip install playwright
python -m playwright install chromium
python tests/check_qr_archive_browser.py
```

Linux-та Chromium жүйелік кітапханалары жоқ болса: `python -m playwright install-deps chromium`.

`tests/` ішіндегі алдыңғы нұсқаларға арналған тесттер сақталған. Кейбірі ескі HTML хэшін, 21 шаблонды немесе бос үлгі карточкаларды күтеді; олар қазіргі QR/фотоархив өзгерістерінің қабылдау критерийі емес. Осы нұсқаның нәтижелері: `verification/qr-archive-*`.

## QR-кодтар және фотоархив жаңартуы

Толық өзгерген файлдар, QR тексеру шектеулері және нақты фото қосу тәртібі `CHANGES_KK.txt` ішінде берілген. QR суреттері бұрынғы `static/images/` ішінде қалды; жаңа папка не сайтқа қосымша тәуелділік енгізілмеді. Оқылмаған YouTube сілтемелері ойдан толтырылмады. Архивтің қолжетімді 20 фотосы сақталып, 5 бос үлгі карточка мен 2 қолжетімсіз фото карточкасы көрсетілімнен алынды. Мектеп және 3D файлдары өзгермеген.

## Ресурстар және дәлелдеме

- Барлық суреттер жергілікті `static/images/` каталогында сақталады.
- Егер суреттің шынымен нақты тарихи қайнар көзі, күні немесе авторы белгісіз болса, сайт бұл ақпаратты "дерек қажет" немесе "сәйкестендіру қажет" ретінде көрсетеді.
- Ойдан жасалған тарихи фотолар, кепілсіз шындық жарияланымдары немесе жалған деректер жоқ; жобада мұндай мәліметтерді көрсете алмайсыз.
- Жоба `IMAGE_SOURCES.md` файлында әр суретке қатысты дереккөзді, мүмкіндігінше авторды, лицензия/status-ті және пайдаланылған беттерді сақтайды.

## Тоқтату

Терминалда `Ctrl + C` басыңыз.

## Көмек

Сайттың жұмыс күйін тексеру үшін Flask іске қосылған кезде браузерде негізгі беттерді ашып, навигация, іздеу және 3D бөлімді тексеруге болады. Тағы да дереккөздер немесе фотолар қосылса, `data/*.json`-дағы жазбаларды дұрыс түрде толықтырыңыз.
