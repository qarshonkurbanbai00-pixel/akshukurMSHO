# Өзгерістер тізімі

## `README.md`
Пайдаланушының тікелей талабы: Windows командалары, 3D URL, офлайн жұмыс, шектеулер және тесттер. Басқа тарихи мәтін өзгермеді.

## `run.bat`
Пайдаланушының тікелей талабы: өз папкасына ауысу, Python тексеру, Flask орнату ұсынысы және қате кезінде pause.

## `static/js/3d.js`
Процедуралық иллюстрациялық орта, raycast таңдау, камера, сенсор/пернетақта, сапа, қате өңдеу. Жоқ GLB және CDN сұраулары алынды.

## `static/models/README.txt`
Жоқ GLB автоматты жүктеледі деген ескі нұсқаулық түзетілді; нақты модель мен иллюстрация ажыратылды.

## `templates/reconstruction.html`
Тек 3D беті: төрт нысан, карточкалар, басқару, маршрут және салыстыру; base.html өзгермеді.

## `tests/test_regression.py`
Тек 3D/run.bat өзгерістеріне қатысты ескі хэш тексеруі ерекшеленді; JS кейін src беретін жасырын img тегі қауіпсіз оқылады. Қалған файлдар жаңа толық SHA-256 тексеруімен қорғалған.

## Жаңадан қосылған файлдар
- `static/css/reconstruction.css`: тек 3D бетінің оқшауланған стилі; бастапқы түстер мен қаріп айнымалылары пайдаланылады.
- `static/data/reconstruction.json`: төрт нысанның карточкасы, камера нүктелері, дерек пен белгісіз тұстар. Барлық бастапқы `data/*.json` өзгеріссіз.
- `static/vendor/three-r128/three.min.js`, `OrbitControls.js`, `LICENSE`: жергілікті Three.js 0.128.0, MIT. https://cdn.jsdelivr.net/npm/three@0.128.0/build/three.min.js және https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/controls/OrbitControls.js; лицензия: https://cdn.jsdelivr.net/npm/three@0.128.0/LICENSE .
- `tests/test_3d_integrity.py`: барлық бастапқы файлдар, басқа маршрут жауаптары, шаблондар, ресурстар, launcher тексерулері.
- `tests/test_reconstruction_browser.py`: Chromium-да нақты интеракция және қате жағдайларын тексеру; сайт іске қосылуына Playwright міндетті емес.
- `verification/reconstruction/`: осы жаңартудың бастапқы аудиті, тест хаттамалары, скриншоттары, өзгеріс тізімі және архив тексеруі.

Ешбір бастапқы файл өшірілген жоқ. Негізгі Python, талаптар, басты бет, base, жалпы CSS/JS, карта, тарихи JSON және фотолар байт деңгейінде сақталды. Бұрынғы `verification/` файлдары қайта жазылған жоқ; олар бастапқы архивтің алдыңғы есептері.
