4. ЖЕТІСПЕЙТІН ЖӘНЕ СӘЙКЕСТЕНДІРІЛМЕГЕН МАТЕРИАЛДАР
Расталған Машырық қажы портреті, мешіт/медресе көрінісі, 1887 жылғы құжат сканы, 1943 жылғы алғашқы мектеп ғимараты/алғашқы сынып фотосы, қазіргі мектеп және мәдениет үйі ғимараттарының фотосы архивте анықталмады.
Осы нысандарға қатысы жоқ суреттер қойылған жоқ. Қазіргі мектеп пен мәдениет үйінің popup-тары нақты атауы/сипаттамасын және расталған фотоның жоқтығы туралы ескертуді көрсетеді.
14 фотоның нақты тұлғасы, нысаны немесе түсірілген жылы расталмаған: олар каталогта identification=unverified деп белгіленді. Файл атаулары WhatsApp... болғандықтан, олардағы адамды тек ұқсастық бойынша атауға болмайды.
Датасы не тұлғасы белгісіз материалдар енді бос қалмайды: фотоархивте бейтарап түсіндірмемен беріледі. Үлкейтіп қарау модалі сақталған.

5. ТЕСТІЛЕУ НӘТИЖЕЛЕРІ
Chromium: 24 бет/экран комбинациясы (12 бет × 1440×1000 және 390×844). 278 тексеру сәтті.
Қошқар ата координатасының дәлдігі, бірегей id, 5 маркердің болуы, мектеп пен мәдениет үйінің бөлек popup-тары, карта санат сүзгілері тексерілді.
Экскурсияның барлық 8 қадамы, Қошқар ата нысанындағы координата, Тарих сүзгісі, 22 сурет каталогы, суретті үлкейту модалі, мобильді мәзір, салыстыру слайдері тексерілді.
3D: canvas ашылды; айналдыруды тоқтату/қосу, камераны қалпына келтіру, каркас батырмалары жұмыс істеді. Бастапқы 3d.js пен реконструкция шаблоны өзгерген жоқ.
Барлық рендерленген жергілікті фото HTTP 200 арқылы ашылды; сынған сурет жоқ; екі өлшемде көлденең overflow жоқ; JavaScript орындалу қатесі жоқ.
Python unittest: 9 тест сәтті. Іске қосу: python -m unittest discover -s tests -v
Бастапқы тұлға деректері, тарих мәтіндері мен даталары, 22 оригинал фото хэштері және қорғалған навигация/анимация/3D/ауызша тарих файлдары салыстырылды.
ШЕКТЕУ: бастапқы ZIP ішінде static/models/mashyryq.glb жоқ. Бастапқы viewer оны сұрағанда HTTP 404 және браузер консолінде тиісті желілік хабарлама бар; бұрыннан бар болжамды модель көрсетіледі. Бұл фото/карта өзгерістерінен туған қате емес, оны жасыру үшін 3D коды өзгертілмеді.
Карта қозғалғанда OpenStreetMap-тың ескі тайл сұраулары ERR_ABORTED болуы мүмкін; бұл Leaflet-тің жаңа көрініске ауысқандағы қалыпты сұрау тоқтатуы. Суреттерге қатысты 404/500 немесе серверлік exception табылған жоқ.
Толық дәлелдер: verification/browser-results.json, unit-tests.txt, coordinate-evidence.json, changed-files.json және screenshots/.

6. АРХИВ ЖӘНЕ ІСКЕ ҚОСУ
ZIP ішінде толық жоба коды, деректер, түпнұсқа суреттер, дайын көрсету көшірмелері, тесттер және осы есеп бар.
Жоба жолы бастапқыдай: MSHO_updated/MSHO/akshukur-digital-chronicle/.
Бастапқы құрылғыға тәуелді .venv және уақытша __pycache__ архивке қосылмайды; requirements.txt өзгерген жоқ.
Іске қосу: жоба папкасында python -m pip install -r requirements.txt, содан кейін python app.py; Windows-та run.bat пайдалануға болады. Браузер: http://127.0.0.1:5000/
Кейін нақты фото қосу: static/images/ ішіне файлды салып, data/places.json ішіндегі тиісті image өрісіне images/НАҒЫЗ_АТАУ.ext жазыңыз. image_url серверде автоматты құрылады. Расталмаған координата үшін lat/lng=null сақталады.
Жаңа суретті data/photos.json каталогына provenance/сипаттамасымен қосуға болады. Координаталар өзгертілсе, дереккөзін де жаңартыңыз.
